# 学习与验收规范 v1.0

## 课程边界
目标是掌握 AI 工具的原理、使用方式与安全工作流。课程以现有 VS Code、Codex、SQL、Spellbook 的实践为载体，不追求实现模型训练或复杂 Agent 框架。

## 单课结构（最多 120 分钟）
1. 概念学习约 30 分钟：问题背景、日常类比、技术原理、常见混淆。
2. 实际实践约 60 分钟：指定环境、操作范围、观察点与可复现验证。
3. 复盘检查约 30 分钟：2～3 个理解问题、结果检查、疑问记录。
不强制按日历赶进度；卡点可延续下次学习。

## 课程完成标准
- **Not started**：尚未正式学习。
- **In progress**：已经正式进入该课，尚未满足验收。
- **Completed**：说明核心概念、完成指定观察/实践（或明确记录不具备条件的替代验证），并完成理解检查。
- **Blocked**：环境、权限或外部依赖阻塞；保留未完成状态并记录原因。
每周验收以 README.md 的“周验收”为准。正式结课需确认 Week 4 综合工作流及人工审核能力。

## 实践安全
- 默认从只读任务开始；写入、执行命令、PR 或权限调整需说明风险和目标范围。
- 不提交 API Key、Token、真实私人数据、密钥或敏感配置。
- 标记证据：看过文件 ≠ 修改文件；dbt compile ≠ 真实数据查询 ≠ 数据质量验收；工具调用成功 ≠ 业务正确。
- 对 Codex 输出检查文件路径、Diff、命令退出状态、测试结果和未验证事项。

## 记录方式
每次只需记录：日期/单元、学到的概念、工具与操作、可核查证据、理解检查结果、遗留疑问、下一步。
跨系统同步时以已验证事实为准；不要在 Notion、GitHub 和 ChatGPT 项目中凭推断填补空白。

## 概念优先顺序
基础：LLM、Prompt、Context、Token、Tool Calling、Agent。
连接：API、MCP、Host/Client/Server、Skills、Rules、AGENTS.md。
执行：Codex、Diff、Sandbox、Approval、Git、测试。
组合：RAG、Workflow、自动化、跨工具协作。
